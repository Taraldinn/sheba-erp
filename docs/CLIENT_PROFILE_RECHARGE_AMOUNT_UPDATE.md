# Client Profile Manual Recharge Amount Update

- Shows Bill Amount, Cost Amount and Net Collection in Client Profile > Quick Actions.
- Discount is always deducted from Bill Amount only.
- Discount never changes Cost Amount.
- Net Collection = Bill Amount - Discount.
- Offer buy-days and Manual Days update Bill/Cost/Net amounts live.
- Existing tenant Recharge Discount Mode controls whether the Discount input is visible.
- Backend already clamps discount to the gross bill amount and preserves recharge validity.
