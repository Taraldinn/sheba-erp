# Sheba ISP ERP & SaaS-Admin v1 Stable Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the certified v1.0.0 General Availability (GA) stable release of the Sheba ISP ERP Backend (`backend/`) and SaaS Control Plane (`sass-admin/`) deployed on FuncHole (`fur2a7.funchole.dev`), backed by managed PostgreSQL (`defaultdb`), with 100% test pass rate, migration zero-debt, Vitest frontend tests, and UI/UX resilience.

**Architecture:** Next.js static export for `sass-admin` deployed as a FuncHole `STATIC` Function at `/*`, Node ESM Edge BFF deployed as a FuncHole `NODE` Function at `/api/v1/*` proxying to the Django backend, backed by FuncHole managed PostgreSQL (`defaultdb`), unified through the FuncHole Gateway (`fur2a7.funchole.dev`).

**Tech Stack:** Django 6.1 / DRF, Next.js 16.3.6, React 19.3, HeroUI 3.2.6, Vitest, React Testing Library, TypeScript 5.9, FuncHole MCP (`funchole`), PostgreSQL 16.

- [ ] **Step 2: Implement route error boundary `sass-admin/app/error.tsx`**

Create `sass-admin/app/error.tsx`:
```tsx
"use client";

import { useEffect } from "react";
import { Button, Card, CardHeader, CardBody, CardFooter } from "@heroui/react";

export default function GlobalError({
  error,
  reset,
}: {
  error: Error & { digest?: string };
  reset: () => void;
}) {
  useEffect(() => {
    console.error("Route error captured:", error);
  }, [error]);

  return (
    <div className="min-h-screen flex items-center justify-center p-6 bg-background">
      <Card className="max-w-md w-full border border-danger/30 bg-surface/80 backdrop-blur-md shadow-2xl">
        <CardHeader className="flex flex-col items-start gap-1 pb-2">
          <span className="text-xs font-semibold uppercase tracking-wider text-danger">System Error</span>
          <h2 className="text-xl font-bold text-foreground">Something went wrong</h2>
        </CardHeader>
        <CardBody className="py-2 text-sm text-muted-foreground">
          <p>{error.message || "An unexpected error occurred while loading this view."}</p>
          {error.digest && (
            <p className="mt-2 text-xs font-mono bg-default-100 p-2 rounded text-foreground/80">
              Digest: {error.digest}
            </p>
          )}
        </CardBody>
        <CardFooter className="flex gap-3 justify-end pt-4">
          <Button variant="outline" onPress={() => (window.location.href = "/")}>
            Back to Dashboard
          </Button>
          <Button color="primary" onPress={() => reset()}>
            Try Again
          </Button>
        </CardFooter>
      </Card>
    </div>
  );
}
```

import { buildUrl, getApiBase } from "@/lib/api";

describe("lib/api", () => {
  it("builds URL with query parameters properly", () => {
    const url = buildUrl("https://api.shebafi.xyz/api/v1/saas/tenants", { page: 1, search: "acme" });
    expect(url).toContain("page=1");
    expect(url).toContain("search=acme");
  });

  it("handles empty query parameters without trailing question mark", () => {
    const url = buildUrl("https://api.shebafi.xyz/api/v1/saas/tenants", {});
    expect(url).toBe("https://api.shebafi.xyz/api/v1/saas/tenants");
  });

  it("resolves API base URL correctly", () => {
    const base = getApiBase();
    expect(base).toBeDefined();
    expect(typeof base).toBe("string");
  });
});
